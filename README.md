# Tugas PPB - Struktur Navigasi Flutter

Aplikasi contoh sederhana bertema media sosial untuk memenuhi komponen:
- AppBar: logo, stories, dan notifikasi.
- NavigationBar bawah: Beranda, Search, Reels, Shop, Profil.
- Drawer: Pengaturan, Aktivitas, Arsip, Keluar.
- EndDrawer: Pesan Masuk, Permintaan, Pengaturan.
- Stack navigation: buka detail postingan, komentar, likes, dan share.
- Profil: foto/avatar, nama, bio, statistik, dan daftar postingan.

## Cara menjalankan
1. Pastikan Flutter SDK sudah terpasang.
2. Buka terminal di folder proyek ini.
3. Jalankan `flutter pub get`.
4. Jalankan `flutter run`.

Jika ingin membuka di VS Code, pilih **Open Folder** lalu pilih folder `flutter_navigasi_ppb`.

Catatan: ini adalah contoh tugas sederhana, bukan aplikasi media sosial sungguhan. Tombol interaksi dibuat sebagai demo UI.
